WHY IT’S A LOOP

The next change
starts with the decision.

Retained rule from this delivery: primary actions follow the theme palette; a different purpose gets a different semantic role.

When adding a destructive action, the next contributor has a reason to introduce a separate role instead of changing every primary button.

02 / CONNECT YOUR AGENT

Bring the outcome you need.

Load the companion skill, then ask your coding agent to investigate a problem and recommend the first delivery. Installing the package does not activate your agent.

Connect your coding agent ↗

Engine Repeatable code evidence.

Agent Diagnosis, delivery, and verification.

Your team Priorities, policy, and releases.

Do we need an existing design system?

No. Your agent can recommend and build a suitable foundation, or extend the library and documentation you already use. The agreed product workflows determine the scope.

What does the engine check?

Selected token and styling code. Layout, behavior, accessibility, and design decisions need rendered review. Read the supported checks and limits.

Does it work in the background?

A person or agent starts the work. The optional Claude Code hook reports after supported edits; it does not prevent or repair edits. CI is a separate setup.

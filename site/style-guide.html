05 / Illustration & icons

Light has a purpose.

Use transparent glass, shallow perspective, and spectral edges to explain the work. The visual should make the idea easier to understand.

The website mark

Use the original D/S outline with the full name in the header. The current header renders the mark at 42px. Keep its proportions and spectral fill; use the same SVG for the favicon.

Three rings. A stationary background.

Expressive art, quiet interface

Keep the cyan → blue → lilac → rose → warm-white spectrum inside illustration. Reserve glows and glass for the loop and explanatory objects.

For new UI icons, follow the existing outline convention: 24-unit viewbox, 1.5px stroke, rounded caps. Pair them with labels; give icon-only controls an accessible name.

Keep the three visual contexts distinct.

Website: violet-black surfaces and purple actions. Process artwork: the spectral palette. Sample product UI: warm white and plum inside its own frame. The intentionally inconsistent “before” examples are not style references.

06 / Motion

Explain, then settle.

Motion reveals a relationship or a change. Visitors should be able to understand the page without waiting for a loop or moving a slider.

01Enter view

Begin only when the comparison introduction is visible.

02Hold · 1 second

Give the “before” state a moment to register.

03Reveal · 2.8 seconds

Sweep once, leave “after” visible, and offer replay.

Give control back

Pause playback offscreen and in hidden tabs. Manual input takes over immediately. Keep pause, replay, keyboard controls, and visible focus available. Never move the page or capture scrolling.

Respect reduced motion

Show the completed comparison and assembly immediately. Stop ambient movement and parallax. Keep content readable without JavaScript. The hero background’s three ellipses remain stationary.

The hero’s separate process sequence uses four 6-second stages. The assembly demo reveals four foundations over 5.7 seconds. Timings belong to each demonstration; they are not universal animation tokens.

07 / Using the language

Build from what is here.

Use this page as the visual reference. Read the relevant CSS and existing markup before adding another style or component.

Foundation
A shared visual decision: color roles, type, space, shape, or motion.
Component
A reusable interface part with a clear purpose and behavior, such as an action or disclosure.
Pattern
Components arranged to solve a recurring task, such as an introduction followed by evidence.
Illustration
An authored explanation. Its decorative colors and materials stay local.

Before adding a style

  1. Find the closest existing example and reuse its classes.
  2. Use a shared property when its role matches the need.
  3. Keep a justified one-off treatment local and record why.
  4. Check a narrow screen, keyboard focus, and reduced motion.
  5. Update this reference when a shared decision changes.
